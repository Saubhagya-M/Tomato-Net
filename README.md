# 🍅 Tomato-Net — AI Tomato Disease Detection System

Tomato-Net is an AI-powered tomato leaf disease detection system built using Deep Learning, TensorFlow, and Streamlit.

The model can identify multiple tomato plant diseases from uploaded leaf images and provide:

* 🌱 Disease description
* 💊 Treatment suggestions
* 🧪 Fertilizer recommendations
* 📷 Camera-based disease detection

---

# 🚀 Features

✅ AI-powered tomato disease detection
✅ Deep learning CNN model
✅ Streamlit web interface
✅ Fast image prediction
✅ Disease information system
✅ Fertilizer recommendations
✅ Treatment suggestions
✅ Clean and responsive UI

---

# 🧠 Diseases Supported

The model can detect:

* Tomato Bacterial Spot
* Tomato Early Blight
* Tomato Late Blight
* Tomato Target Spot
* Healthy Tomato Leaf

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Saubhagya-M/Tomato-Net.git
```

---

## 2️⃣ Open Project Folder

```bash
cd Tomato-Net
```

---

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
streamlit run app.py
```

---

# 🧪 Model Training

To train the CNN model:

```bash
python model_training/train_model.py
```

# 📸 How It Works

1. Upload a tomato leaf image
2. AI model analyzes the leaf
3. Disease is predicted
4. App displays:

   * Disease name
   * Description
   * Treatment
   * Fertilizer suggestions
